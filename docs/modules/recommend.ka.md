# დოკუმენტაცია — `src/recommend.py`

> 🇬🇧 English version: [recommend.md](recommend.md)

**როლი:** სეგმენტების ზარალიანობის გარდაქმნა კრედიბილურობით შეწონილ, შეზღუდულ ფასის კორექციებად.
**დამოკიდებულება:** `metrics.aggregate_by`-ის შედეგი. **გამოიყენება:** `run`.

---

## 1. ძირითადი იდეა
თითოეული სეგმენტის დაკვირვებული ზარალიანობა შედარდება **სამიზნე** ზარალიანობას. სეგმენტი, რომელიც სამიზნეზე „ცხელია“, ნაკლებადაა შეფასებული → ტარიფი იზრდება; „ცივი“ → მცირდება. მცირე რაოდენობის ზარალის მქონე სეგმენტები ხმაურიანია, ამიტომ მათი საკუთარი ინდიკაცია **მთელი პორტფელის** ინდიკაციას ერწყმის.

---

## 2. ფორმულები

### 2.1 ნედლი კორექცია (სეგმენტის საკუთარი გამოცდილება)
```
raw_correction = (loss_ratio / target_loss_ratio) - 1
```
- თუ `loss_ratio > target` → დადებითი (ფასის ზრდა); `< target` → უარყოფითი.
- `NaN` ზარალიანობა (ჯერ არ არის გამომუშავებული პრემია) → `raw_correction = NaN` → მოქმედება „No data“.

### 2.2 საბაზისო კორექცია (კრედიბილურობის დანამატი)
```
base_correction = (portfolio_loss_ratio / target_loss_ratio) - 1
```
ამ პორტფელზე: 70.6% / 60% − 1 = **+17.7%**. სეგმენტი, რომელსაც სანდო გამოცდილება არ აქვს, მთელ პორტფელთან ერთად მოძრაობს და არ რჩება „ცვლილების გარეშე“.

### 2.3 კრედიბილურობა (limited fluctuation, კვადრატული ფესვის წესი)
```
credibility = min(1, sqrt(n_claims / full_credibility_claims))
```
`full_credibility_claims = 1,082` — კლასიკური სტანდარტი ზარალის სიხშირის ±5%-იანი სიზუსტით შესაფასებლად 90%-იანი ალბათობით.

### 2.4 რეკომენდებული კორექცია (შეზღუდული)
```
recommended_correction = clip(credibility * raw_correction + (1 - credibility) * base_correction,
                              -max_correction, +max_correction)
relative_to_portfolio  = (1 + recommended_correction) / (1 + base_correction) - 1
```
`relative_to_portfolio` აჩვენებს, სად სჭირდება პორტფელზე **მეტი** (> 0) ან **ნაკლები** (< 0) ზრდა.

### 2.5 რეკომენდებული ტარიფი და % ცვლილება
```
recommended_premium_rate = premium_rate * (1 + recommended_correction)
recommended_rate_change_pct = recommended_correction * 100
```

### 2.6 მოქმედების ლეიბლი
```
action = "Increase"  თუ recommended_correction >= 0.05
       = "Decrease"  თუ recommended_correction <= -0.05
       = "Hold"      სხვა შემთხვევაში      ("No data", თუ ზარალიანობა არ არის)
```

## 3. ნაგულისხმევი პარამეტრები
| პარამეტრი | ნაგულისხმევი | მნიშვნელობა |
|---|---|---|
| `target_loss_ratio` | `0.60` | მისაღები ზარალიანობა (მენეჯმენტის დაშვება) |
| `full_credibility_claims` | `1,082` | სრული კრედიბილურობისთვის საჭირო ზარალების რაოდენობა |
| `max_correction` | `0.50` | ზღვარი ±50% |
| `portfolio_loss_ratio` | ითვლება შემავალი მონაცემებიდან | კრედიბილურობის დანამატი; `run.py` პორტფელის მაჩვენებელს გადასცემს, რომ ყველა ჭრილში ერთი და იგივე ბაზა იყოს |

ყველა ფუნქციის არგუმენტია — შეცვალეთ ისინი ლოგიკის შეხების გარეშე.

## 4. ფუნქცია: `recommend(seg_metrics, ...) -> DataFrame`
ამატებს სვეტებს: `credibility, raw_correction, base_correction, recommended_correction,
relative_to_portfolio, recommended_premium_rate, recommended_rate_change_pct, action`.

### `summarize_recommendations(rec) -> DataFrame`
აბრუნებს კომპაქტურ ხედს (სეგმენტის განზომილებები + ძირითადი მეტრიკები + კორექციები + მოქმედება), დალაგებულს `earned_premium`-ით კლებადობით. სვეტები ირჩევა მხოლოდ მაშინ, თუ არსებობს.

## 5. შედეგები რეალურ მონაცემებზე (1,056 კომპოზიტური სეგმენტი)
- მედიანური კრედიბილურობა 0.068; 16 სეგმენტი სრულად კრედიბილურია.
- მოქმედებები: Increase 1,044 · Hold 8 · Decrease 4 — მთელ პორტფელს +17.7% სჭირდება.
- პორტფელთან შედარებით: **238** სეგმენტს +5%-ზე მეტი დამატებითი ზრდა სჭირდება, **90**-ს — 5%-ზე მეტით ნაკლები.

v1 იყენებდა `credibility = min(1, earned_premium / GEL 5M)`-ს ნულოვანი დანამატით: მედიანური კრედიბილურობა 0.003 იყო და 1,262-დან 1,205 სეგმენტი „Hold“-ზე იდგა. იხ. [მეთოდოლოგიის გადახედვა](../review.ka.md).
