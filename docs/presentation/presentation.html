Section 1

Business Problem & Objectives

CASCO is comprehensive motor insurance. The book is under-priced: the portfolio loss ratio is 70.6% against a 60% management target — roughly an 18% average under-pricing. The goal is a transparent, defensible pricing model that (a) explains where the book loses money and (b) indicates risk-adequate rate corrections.

Objective 1 — Diagnose

Segment the book along the four rating dimensions and surface the hot / cold segments driving the 70.6% loss ratio.

Objective 2 — Indicate

Produce credibility-weighted, capped rate corrections (±50%) from each segment's experience vs. the target loss ratio.

Objective 3 — Model

Build individual-risk frequency × severity models validated out-of-time, with a model-based rate indication and elasticity response.

Definition: Loss Ratio (LR) = Incurred Claims ÷ Earned Premium. A pure-premium model estimates E[cost] = E[N] · E[S] where N = claim count (frequency) and S = claim amount (severity). Technical premium = model_pp / target_LR.

Cleaning rules (load_data.py)

  • Keep only CASCO policies, physical clients, personal-use vehicles.
  • Validate claims; convert suminsured to GEL via FX; compute earned_premium.
  • Aggregate claims per policy (zeros filled) and compute loss_ratio only where earned_premium > 0 (safe divide → NaN otherwise).
  • Derive exposure = earned_premium.clip(lower=0) — used as the GLM offset / GBM weight.
  • Enrich with deductible_type (yes/no), eligible_driver_count, min_driver_age, carage from the enrcols file.
This single layer is the only place raw data is touched — every downstream module consumes the same clean frame, so changes cascade predictably.

Part A — Segment Experience-Rating

Segmentation (segments.py)

Four rating dimensions, collapsed for stability:

Age

18–20 · 21–25 · 26–29 · 30–40 · >40

Vehicle type

SUV-type · Sedan · Coupé/Cabrio (collapsed to 3)

Yes / No

Sum insured

USD bands from the brief (≤5k · 1k-wide bands 5k–50k · >50k)

→ 1,264 composed segments (4 dims × bands).

Metrics (metrics.py)

  • aggregate_by computes per-segment loss ratio, policy rate, frequency, severity.
  • safe_div returns NaN (not inf) on zero exposure — prevents silent distortions.
  • aggregate_overall gives the one-line portfolio totals.

Recommendations (recommend.py)

  • Correction = credibility-weighted experience vs. target_loss_ratio = 0.60.
  • Capped at ±50%; thin segments shrink toward the portfolio mean via credibility Z.
  • Action label (increase / decrease / hold) attached for underwriters.
All corrections are point estimates that ignore elasticity — a documented limitation (price changes may shift demand/mix).
Section 5

Part B — Advanced Statistical Models

Frequency (frequency.py)

  • Poisson & Negative-Binomial GLM with offset = log(exposure).
  • LightGBM Poisson GBM using log_exposure as a feature (trees can't use an offset like GLMs).
  • NegBin started from Poisson MLE with alpha=0.1 (never 0 → avoids log(0) BFGS blow-up).
  • Offset re-applied at predict — a GLM fit with an offset but scored without it predicts rate×exposure, not expected count.

Severity (severity.py)

  • Models claim amount per claim (zero claims already in frequency).
  • LogNormal GLM (Gaussian on log(amount)) + LightGBM Gamma GBM.
  • Gamma GLM dropped — statsmodels IRLS/BFGS diverges on this heavy-tailed target (blows up or falls into an inverted-local optimum).

Pure premium (pure_premium.py)

  • E[cost] = E[N]·E[S]: multiplicative Poisson×LogNormal and direct Tweedie (power 1.5) on incurred_claim.
  • Tweedie handles the zero-mass + continuous tail in one model.
  • calibration_factor = mean(actual $) / mean(predicted $) corrects the level before indication.

Credibility (credibility.py)

  • Bühlmann-Straub: Z_i = n_i / (n_i + k), k = EPV/VPP.
  • n_i = policy count (not dollar exposure — dollar exposure would make every segment fully credible).
  • Shrinks each segment's observed pure premium toward the portfolio mean.

Pricing (pricing.py)

  • Technical premium = model_pp / target_LR (target 0.65 in Part B).
  • Rate change capped ±50%; elasticity-based volume response (−0.5).
  • Calibration factor applied so the model level is right before indication.

Validation (validation.py)

  • Monthly actual-vs-predicted loss-ratio monitoring on the hold-out.
  • Out-of-time insurance Gini (Lorenz / accuracy-ratio form).
  • Level calibration check (ratio ≈ 1.0 means well-calibrated in level).
Section 6

Key Modelling Decisions & "Why"

DecisionWhy
Time-based split (not random)Random split leaks future policies into training and inflates Gini; the test window must be the most recent period.
offset = log(earned_premium)Standardises each policy to one unit of exposure; re-applied at predict or the model predicts rate×exposure, not expected count.
Drop Gamma GLM for severityIRLS/BFGS diverges on the heavy tail (blows up or stuck in inverted local optimum); LogNormal GLM + Gamma GBM are stable.
Multiplicative freq×sev and TweedieDecomposes the driver of cost and gives a cross-check; Tweedie natively models zero-inflated claims.
Credibility uses policy count nDollar exposure would make every segment "fully credible"; count reflects real experience volume.
±50% correction cap + credibilityPrevents thin segments from producing destabilising extreme corrections.
Calibration factor before indicationThe multiplicative model under-predicts the average pure premium (factor ≈ 1.68); corrects level, not shape.
Two target loss ratios (0.60 / 0.65)Part A and Part B are separate management parameters; both must be set before deployment.
Section 7

Engineering Strength — Tests, EDA, Experiments

A model you cannot repeat or defend is not shippable. Three layers make the result auditable.

Tests (tests/)

48 tests · 11 modules · 0 failures. Each test file documents why it exists. The suite is a regression net that already caught a NegBin alpha=0 divergence (20-min lock-up) and an experiments KeyError: 'segment'.

EDA (src/eda.py)

9-step function: overview, frequency, severity, exposure, segments, time trend, feature relationships, zero-claim deep-dive, credibility preview — each shows the facts the models rely on.

Experiments (src/experiments.py)

8 what-if probes that prove each modelling choice: Gamma GLM divergence (EXP 2), log_exposure ablation (EXP 5), policy-count vs dollar credibility (EXP 6), calibration effect flipping the indication sign (EXP 7), NegBin vs Poisson (EXP 8).

Process rule: any change in load_data.py, a model, or a metric is "ready" only when python -m tests.run_all is green and python -m src.experiments still completes. This is the cheapest way to keep the book trustworthy.

Key insights

  • Young drivers (21–29) are the worst on loss ratio and already pay the highest per-policy rate (~2× the >40 rate) — the book still loses money on them.
  • No-deductible policies run ~19 pts worse (0.743 vs 0.555) at the same average rate — deductible choice is not priced; load or discount accordingly.
  • Low sum-insured cars are the most under-priced; the rate curve is inverse to risk (cheap cars under-priced, expensive cars over-priced).
  • Test calibration: actual LR 0.8225 vs predicted 0.7838 (target 0.65) → model is well-calibrated in level (ratio ≈ 1.05) and shows the book is ~17–22% above target.
  • Avg indicated rate change +18.5%; elasticity implies volume −9.3%; 22,505 policies recommended for increase, 5,735 for decrease.
