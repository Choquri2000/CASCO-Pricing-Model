სრული, აუდიტისთვის მისაღები ტარიფის კონვეიერი — ნედლი პოლისების/ზარალების მონაცემებიდან სეგმენტის გამოცდილებით-რეიტინგამდე და ინდივიდუალურ-რისკის სტატისტიკურ მოდელებამდე, სრული ტესტის, EDA-სა და ექსპერიმენტის ჩარჩოთი.

სექცია 1

ბიზნეს პრობლემა და მიზნები

CASCO არის ავტომობილის ყოვლისმომცველი დაზღვევა. წიგნი არასაკმარისად არის ტარიფიკებული: პორტფელის ზარალიანობა შეადგენს 70.6% 60%-იანი მენეჯმენტის სამიზნესთან შედარებით — ეს არის დაახლოებით 18%-იანი საშუალო ნაკლებად-ტარიფიკება. მიზანია გამჭვირვალე, დასაცავი ტარიფის მოდელი, რომელიც (ა) ხსნის სად აკლია წიგნს ფული და (ბ) მიუთითებს რისკ-ადეკვატურ ტარიფის კორექციებს.

მიზანი 1 — დიაგნოსტიკა

წიგნის დაყოფა რეიტინგის ოთხ განზომილებაზე და 70.6%-ის გამომწვევი ცხელი/ცივი სეგმენტების გამოვლენა.

მიზანი 2 — ინდიკაცია

კრედიბილურობით წონითდებული, შეზღუდული (±50%) ტარიფის კორექციების მითითება თითოეული სეგმენტის გამოცდილებისა და სამიზნე ზარალიანობის მიხედვით.

მიზანი 3 — მოდელირება

ინდივიდუალურ-რისკის სიხშირის × სიმძიმის მოდელების აგება, რომლებიც დროით გარეთ არიან ვალიდირებული, მოდელზე დაფუძნებული ტარიფის ინდიკაციითა და ელასტიურობის რეაქციით.

განმარტება: ზარალიანობა (LR) = განხორციელებული ზარალები ÷ მიღებული პრემია. სუფთა პრემიის მოდელი ფასავს E[cost] = E[N] · E[S], სადაც N = ზარალის რაოდენობა (სიხშირე), ხოლო S = ზარალის თანხა (სიმძიმე). ტექნიკური პრემია = model_pp / target_LR.

სექცია 5

ნაწილი B — გაფართოებული სტატისტიკური მოდელები

სიხშირე (frequency.py)

  • Poisson-ისა და Negative-Binomial GLM offset = log(exposure)-ით.
  • LightGBM Poisson GBM იყენებს log_exposure ფიჩერად (ხეებს ოფსეტის გამოყენება ვერ შეუძლიათ ისე, როგორც GLM-ებს).
  • NegBin იწყება Poisson MLE-დან alpha=0.1-ით (არასდროს 0 → თავიდან იცილებს log(0) BFGS გაფუჭებას).
  • ოფსეტი ხელახლა გამოიყენება პროგნოზის დროს — GLM, რომელიც ოფსეტით არის მორგებული, მაგრამ ოფსეტის გარეშე შეფასებული, ექსპოზიციის რაოდენობას აჩვენებს, არა მოსალოდნელ რაოდენობას.

სიმძიმე (severity.py)

  • მოდელირებს ზარალის თანხას ერთ ზარალზე (ნულოვანი ზარალები უკვე სიხშირეშია).
  • LogNormal GLM (Gaussian log(amount)-ზე) + LightGBM Gamma GBM.
  • Gamma GLM მოიხსნა — statsmodels IRLS/BFGS იშლება ამ მძიმედ-კუდიან სამიზნეზე (თავთაბარი იფეთქებს ან ინვერსიულად-რანჟირებულ ლოკალურ ოპტიმუმში ეცემა).

სუფთა პრემია (pure_premium.py)

  • E[cost] = E[N]·E[S]: მრავლობითი Poisson×LogNormal და პირდაპირი Tweedie (ძალა 1.5) incurred_claim-ზე.
  • Tweedie მართავს ნულოვან მასას + უწყვეტ კუდს ერთ მოდელში.
  • calibration_factor = mean(actual $) / mean(predicted $) ასწორებს დონეს ინდიკაციამდე.

კრედიბილურობა (credibility.py)

  • Bühlmann-Straub: Z_i = n_i / (n_i + k), k = EPV/VPP.
  • n_i = პოლისების რაოდენობა (არა დოლარის ექსპოზიცია — დოლარი ყველა სეგმენტს სრულად კრედიბილურს გახდის).
  • ამცირებს თითოეული სეგმენტის დაკვირვებულ სუფთა პრემიას პორტფელის საშუალოსკენ.

ტარიფიკაცია (pricing.py)

  • ტექნიკური პრემია = model_pp / target_LR (სამიზნე 0.65 ნაწილ B-ში).
  • ტარიფის ცვლილება შეზღუდულია ±50%-ით; ელასტიურობაზე დაფუძნებული მოცულობის რეაქცია (−0.5).
  • კალიბრაციის ფაქტორი გამოიყენება ინდიკაციამდე დონის გასწორებად.
