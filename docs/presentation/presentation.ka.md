## 1 · ბიზნეს პრობლემა და მიზნები
CASCO არის ავტომობილის ყოვლისმომცველი დაზღვევა. წიგნი **არასაკმარისად არის ტარიფიკებული**:
პორტფელის ზარალიანობა შეადგენს **70.6%** 60%-იანი მენეჯმენტის სამიზნესთან შედარებით — ეს არის
დაახლოებით **18%-იანი საშუალო ნაკლებად-ტარიფიკება**.

> **ზარალიანობა (LR)** = განხორციელებული ზარალები ÷ მიღებული პრემია.
> **სუფთა პრემია** ფასავს `E[cost] = E[N] · E[S]`, სადაც `N` = ზარალის რაოდენობა (სიხშირე),
> ხოლო `S` = ზარალის თანხა (სიმძიმე). **ტექნიკური პრემია** = `model_pp / target_LR`.

| მიზანი | რას აწვდით |
|---|---|
| **დიაგნოსტიკა** | წიგნის დაყოფა 4 რეიტინგის განზომილებაზე; 70.6%-ის გამომწვევი ცხელი/ცივი სეგმენტების გამოვლენა. |
| **ინდიკაცია** | კრედიბილურობით წონითდებული, შეზღუდული (±50%) ტარიფის კორექციები სამიზნე ზარალიანობის წინაშე. |
| **მოდელირება** | ინდივიდუალურ-რისკის სიხშირის × სიმძიმის მოდელები, რომლებიც **დროით გარეთ** არიან ვალიდირებული, ტარიფის ინდიკაციით + ელასტიურობით. |

## 3 · ამოხსნის არქიტექტურა
ორი თანამშრომელი ნაწილი იზიარებს გაწმენდილ ჩარჩოს. ნაწილი A = სწრაფი, განმარტვადი სეგმენტური
ხედი; ნაწილი B = ინდივიდუალურ-რისკის მოდელები, რომლებიც დროით გარეთ არიან ვალიდირებული.

**ნაწილი A — სეგმენტის გამოცდილებით-რეიტინგი (`run.py` კოორდინაციას უწევს):**
`load_data` → `segments` → `metrics` → `recommend` → `run` (CSV + Excel)

**ნაწილი B — გაფართოებული ინდივიდუალურ-რისკის მოდელები:**
`features` → `frequency` → `severity` → `pure_premium` → `credibility` → `pricing` → `validation`

- **დროზე დაფუძნებული გაყოფა:** ტრენინგი `efdate < 2025-01-01`, ტესტი `efdate ≥ 2025-01-01` (გაჟონვის თავიდან აცილება).
- **ექსპოზიცია როგორც ოფსეტი:** `offset = log(exposure)`, სადაც `exposure = earned_premium`; ხელახლა გამოიყენება პროგნოზის დროს.
- **გამონატანები:** 1,264 სეგმენტი, პორტფელის შეჯამება, 6 დაშლის ფურცელი, მოდელის მეტრიკები და მონიტორინგის ცხრილები.

## 4 · ნაწილი A — სეგმენტის გამოცდილებით-რეიტინგი

**სეგმენტაცია (`segments.py`)** — ოთხი რეიტინგის განზომილება, შეკუმშული სტაბილურობისთვის:
- **ასაკი:** 18–20 · 21–25 · 26–29 · 30–40 · >40
- **ავტომობილის ტიპი:** მაღალი გამავლობის · სედანი · კუპე/კაბრიო (შეკუმშული 3-ში)
- **ფრანშიზა:** კი / არა
- **დაზღვეული თანხა:** USD დიაპაზონები დავალებიდან (≤5k · 1k-იანი ბიჯით 5k–50k · >50k)

→ **1,264** შედგენილი სეგმენტი.

**მეტრიკები (`metrics.py`):** `aggregate_by` თვლის სეგმენტის LR/რეიტს/სიხშირეს/სიმძიმეს;
`safe_div` აბრუნებს NaN-ს (არა ∞) ნულოვან ექსპოზიციაზე; `aggregate_overall` იძლევა პორტფელის ჯამებს.

**რეკომენდაციები (`recommend.py`):** კორექცია = კრედიბილურობით წონითდებული გამოცდილება
`target_loss_ratio = 0.60`-ის წინაშე; შეზღუდული ±50%; თხე სეგმენტები შემცირდება საშუალოსკენ
კრედიბილურობით `Z`; მოქმედების ლეიბელი (გაზრდა/შემცირება/შენარჩუნება) ემატება.

> ყველა კორექცია არის წერტილოვანი შეფასება, რომელიც იგნორირებს ელასტიურობას — დოკუმენტირებული
> შეზღუდვა.

## 5 · ნაწილი B — გაფართოებული სტატისტიკური მოდელები

- **სიხშირე (`frequency.py`):** Poisson-ისა და NegBin GLM `offset = log(exposure)`-ით; LightGBM
  Poisson GBM იყენებს `log_exposure` ფიჩერად; NegBin იწყება Poisson MLE-დან `alpha=0.1`-ით
  (არასდროს 0 → თავიდან იცილებს `log(0)` BFGS გაფუჭებას); **ოფსეტი ხელახლა გამოიყენება პროგნოზში**.
- **სიმძიმე (`severity.py`):** მოდელირებს თანხას ერთ ზარალზე; LogNormal GLM + LightGBM Gamma GBM;
  **Gamma GLM მოიხსნა** (IRLS/BFGS იშლება მძიმე კუდზე).
- **სუფთა პრემია (`pure_premium.py`):** `E[cost]=E[N]·E[S]` — მრავლობითი Poisson×LogNormal **და**
  პირდაპირი Tweedie (ძალა 1.5) `incurred_claim`-ზე; `calibration_factor = mean(actual $)/mean(predicted $)`.
- **კრედიბილურობა (`credibility.py`):** Bühlmann-Straub `Z_i = n_i/(n_i+k)`, `k=EPV/VPP`; `n_i` =
  **პოლისების რაოდენობა** (არა დოლარის ექსპოზიცია); ამცირებს დაკვირვებულ სუფთა პრემიას პორტფელის საშუალოსკენ.
- **ტარიფიკაცია (`pricing.py`):** ტექნიკური პრემია = `model_pp / target_LR` (0.65 ნაწილ B-ში); ტარიფის
  ცვლილება შეზღუდული ±50%-ით; ელასტიურობაზე დაფუძნებული მოცულობის რეაქცია (−0.5); კალიბრაციის ფაქტორი ინდიკაციამდე.
- **ვალიდაცია (`validation.py`):** ყოველთვიური ფაქტიკური-საპირისპირო-პროგნოზირებული LR მონიტორინგი
  hold-out-ზე; დროით გარეთ სადაზღვევო Gini; დონის კალიბრაციის შემოწმება (კოეფ. ≈ 1.0).

## 6 · მთავარი მოდელირების გადაწყვეტილებები და „რატომ“

| გადაწყვეტილება | რატომ |
|---|---|
| დროზე დაფუძნებული გაყოფა (არა შემთხვევითი) | შემთხვევითი გაყოფა აჟონებს მომავალ პოლისებს ტრენინგში და ზრდის Gini-ს. |
| `offset = log(earned_premium)` | სტანდარტიზაცია ექსპოზიციის ერთეულზე; ხელახლა გამოყენება პროგნოზის დროს საჭიროა, თუ არა — მოდელი რეითს×ექსპოზიციას წინასწარმეტყველებს. |
| Gamma GLM-ის მოხსნა სიმძიმისთვის | IRLS/BFGS იშლება მძიმე კუდზე; LogNormal GLM + Gamma GBM სტაბილურია. |
| მრავლობითი freq×sev **და** Tweedie | ახსნის ღირებულების მძრავს + გადასასწორებელ შემოწმებას იძლევა; Tweedie ნატურალურად მოდელირებს ნულ-ინფლაციურ ზარალებს. |
| კრედიბილურობა იყენებს **პოლისების რაოდენობას** n | დოლარის ექსპოზიცია ყველა სეგმენტს „სრულად კრედიბილურს“ გახდის; რაოდენობა ასახავს რეალურ მოცულობას. |
| ±50% ზღვარი + კრედიბილურობა | თავიდან იცილებს თხე სეგმენტების დესტაბილიზაციას. |
| კალიბრაციის ფაქტორი ინდიკაციამდე | მრავლობითი მოდელი ნაკლებად პროგნოზირებს საშუალო PP-ს (ფაქტორი ≈ 1.68); ასწორებს დონეს, არა ფორმას. |
| ორი სამიზნე LR (0.60 / 0.65) | ცალკე მენეჯმენტის პარამეტრები; ორივე დასაყენი განთავსებამდე. |

## 7 · ინჟინერიის სიმყარე — ტესტები, EDA, ექსპერიმენტები
მოდელი, რომელსაც ვერ გაიმეორებთ და ვერ დაიცავთ, გამშვები არ არის.

- **ტესტები (`tests/`):** **48 ტესტი · 11 მოდული · 0 ჩავარდნა.** ყოველი ფაილი ადოკუმენტებს *რატომ*
  არსებობს; ნაკრებმა უკვე დაიჭირა NegBin `alpha=0` გადახრა (20-წუთიანი დაბლოკვა) და ექსპერიმენტების
  `KeyError: 'segment'`.
- **EDA (`src/eda.py`):** 9-ნაბიჯიანი ფუნქცია (მიმოხილვა, სიხშირე, სიმძიმე, ექსპოზიცია, სეგმენტები,
